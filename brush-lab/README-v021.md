# v0.21 分层笔触优化

本轮只优化三类人工读笔样本：弘仁转折勾线、马远斧劈候选、沈周短横点。
不是自动笔触识别，也不是从成品唯一反推真实笔序。基础模型仍是未标定的低维毛束、液桥和纸内输运模型。

## 分层决策

| 层级 | 本轮动作 | 收益判断与处理 |
|---|---|---|
| 读笔与路径 | 保存每个原始折点；分别读取勾线、皴面、短横点 | 高收益，已做。旧版稀疏采样会跨过转折 |
| 起行收时序 | 短点改为较早横移，持续接触后再提；斧劈压入回调 | 高收益，已做两轮物理反馈 |
| 尺度与控制 | 小短点使用单独的笔宽配置；0.010 s 有界前馈补偿已有笔锋跟随滞后 | 中高收益，已做；不是改变纸/毛物理参数 |
| 供墨 | 保留真实的相邻笔耗墨；勾线略降低浓度；不自动每笔补墨 | 中等收益，避免把接触不足误判成总墨耗尽 |
| 评价 | 侧缘底色扣除，分报截面宽度、长度覆盖、中心偏差与首中尾浓淡 | 高收益诊断，但未完成图像真值标定；不合成一个艺术质量分 |
| 随机性 | 固定相同种子比较动作，再以第二组纸面/毛束种子复验 | 用于查脆弱性；两个种子不是统计泛化证明 |
| 毛笔尺寸物理 | 真实笔号对应毛长、毛量、刚度、容量与导流 | 暂缓，现有横向宽度不能当整支毛笔几何缩放 |
| 纸绢与流体 | 多种底材定量标定、全三维毛束耦合、干燥颗粒再分配 | 暂缓，实验/实现成本高，当前先解决笔形与动作 |
| 优化搜索 | 大范围混合参数蒙特卡洛 | 暂缓；先修正观测与评价后再作分笔类的小范围搜索 |

## 实际改动

`inkscape_lab/stroke_opt21.py` 保留 v0.20 的物理会话接口。R1 保存原始折点，改写三类动作，小短点改用 detail 笔束。R2 加入有界前馈（0.010 秒，勾线最多0.28毫米，其他最多0.22毫米）、回调斧劈压入、微调短点姿态和勾线浓度。每笔的物质库存与纸状态在连续会话中保留。原 `stroke_reading.py` 和物理方程未改。

前馈是控制器试验：对目标纸面路径求速度，再给手部路径加有限的速度提前量，补偿模型已有的一阶笔锋跟随。不是声称真实画家按该公式运笔。

`stroke_score21.py` 仅在物理模拟结束后读图，用于诊断；图像像素、掩膜或噪声贴图均不进入落墨计算。绢纹会使截面连接区断开，马远的绝对宽度估计可信度低；不据此自动选胜者。原作扫描的光学浓度也不能视为实物定量浓度。覆盖率仅表示人工路径采样处存在可检测墨迹。

## 运行

在 `brush-lab/` 下运行。核心实验需要 Python、NumPy、SciPy、Pillow，以及 Linux 或 WSL 中的 g++。脚本先构建原生后端，再以进程并行执行。

```sh
python -m pip install numpy scipy Pillow
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python -X utf8 -m inkscape_lab.stroke_opt21 --round 1 --workers 3
python -X utf8 -m inkscape_lab.stroke_opt21 --round 2 --workers 3
python -X utf8 -m research21.holdout
```

[`references19/manifest.json`](references19/manifest.json) 保留馆藏和裁窗的出处。重跑早期读笔须按目录记录准备本地参考图。`stroke20/r3/` 保存第二种子比较所需的三份基线任务。旧版山体、拼图和交付流程使用各自原始输入包及模拟结果。当前单笔模型可从[仓库首页](../README.md)独立启动。

最终源码中 R2 的修改受 variant 条件保护，R1 手势不变。历史独立 ZIP 内含对应源码、物理场和继续绘制状态。已有结果指纹不同则拒绝覆盖，应使用新输出路径。保存的 pickle 仅用于本项目自己的可信状态。

## 视觉判断

R1 的短横点比旧版更有横向延伸，但过细，斧劈则过宽。R2 回调后，短点长度覆盖与转折末段更好；斧劈并未达到明确胜出。仍然缺少原作中的部分宽笔擦痕、非均匀的成束接触和层叠关系。保留这些限制，不以数值分数宣称“已还原原作”。

最终供后续驱动调用的接口为 `selected_task(row, seed)`：勾线与短横点暂选 R2，斧劈返回 v0.20 R3。两个种子中的平均路径覆盖分别为：勾线第二种子0.796→0.899，短横点0.767→0.921；斧劈0.843→0.822。覆盖改善不等于纸墨质感得到同幅度改善。12次会话通过守恒检查，最大相对误差约5.8e-16。
