# R02 → 笔触模块：景片接口建议

状态：接口建议，尚未完成另一套笔触模块的连接。

## 资产语义

所有画面字段共享同一 `uv_domain`、参考相机、山体/坡面身份、画纸尺度和版本。几何只负责投影与空间关系，不另画一条高精度可见轮廓。

| 字段 | 含义 |
|---|---|
| `ink_rgba_premultiplied` | 墨层颜色与墨层自身 alpha；保留皴、勾、飞白、干湿边缘和已有扩散。不要提前合到不透明纸底。 |
| `interior_coverage` | 山体内部及留白对后景的覆盖，独立于墨色浓淡。不要用“白=透明”代替。 |
| `uv_domain` | 比实际墨迹外缘更大的画幅；包含扩散、笔锋和所需采样余量。 |
| `proxy_mesh / depth_proxy` | 固定空间支架，不从墨色推断，不用自身三角形边界裁出山形。 |
| `reference_camera / view_domain` | 参考视点与已承诺的有效观察范围。 |
| `mountain_id / region_id / version` | 续画、缓存和局部更新的稳定身份。 |
| `stroke_ids / stroke_plan` | 条件允许时保留，支撑多视点对应与原笔迹复用。 |

`interior_coverage` 可由笔触计划的轮廓意图和区域填充共同形成；不要求只有实际着墨的位置才有覆盖。重要的是它与勾线的语义来自同一绘画计划，而不是另建一条精细硬裁切线。粗区域作为内部遮挡约束可以保留，但不应该越过外缘墨迹形成可见的白边。

## 合成

设墨层预乘颜色为 J，墨层 alpha 为 A，内部覆盖为 C，统一纸色为 P：

```
alpha = A + (1 - A) * C
rgb_premul = J + (1 - A) * C * P
result = rgb_premul + background * (1 - alpha)
```

山内 C=1，保留白纸遮挡；边缘 C 向内退让，墨层可越过它；更外侧 A=C=0。这不是把整个山按墨色统一变透明，也不是向世界空间生成漂浮墨粒。

墨迹的干边可保留尖利/碎裂，湿边沿笔触求解结果渐淡，不要求全山统一高斯模糊。羽化和扩散应固定在画纸/景片坐标中，随同一支架投影；不叠加每帧随机噪声。

PNG 若保存 straight alpha，上传和后续合成需要明确转换；不得把已经预乘的 RGB 再乘一次 alpha。R02 的成品贴图保存 straight RGBA，WebGL 上传预乘后再生成 mipmap。

## 几何余量与版本

扩大的是承载域，不是山的尺寸。域外深度可用邻近支架稳定延拓，只承担投影，不参与可见轮廓定义。余量应覆盖真实笔锋、扩散和采样需要；R02 的 10%/5% 只是本次示例，非通用阈值。

相邻观察版本的结构、覆盖和笔迹要先对齐，再交接。R02 仅改变主峰内部既定区域，A/B 的最终 alpha 完全相同。之后若允许覆盖随版本变化，必须另测双轮廓、淡边移动和内部留白遮挡，不可直接沿用本轮“alpha 相同”的测试结论。

## 旧图适配器退出条件

收到原生墨层与内部覆盖后，替换 `build_assets.py` 里的纸底归一化、图像闭合/填洞和宽松语义区域，不动游线、代理几何及运行时合成接口。

必须补测：内部留白、外部空白、干笔孔隙、跨轮廓湿墨、叠山软边、图幅边界、倒退复现、多尺度采样及相邻版本交接。不要把 RGB 旧图分割的偶然成功当成接口完成。
