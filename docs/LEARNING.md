# 中国画单笔学习笔记

## 物理和动作

- 先用纸面毫米定义画幅和接纸宽度，再用像素密度换算。A4 横放以高度 1080 px 对应 210 mm 时，8 mm 的接纸宽约为 41 px。更密的栅格需要同尺度的毫纹证据，插值只增加样点。
- 顺逆由行笔切向与笔根至锋尖的投影确定。在有拍摄标记时保留真实侧别。静图上量出的墨色重心属于成迹，力道、锋尖侧别和画家的执笔习惯分别靠动作记录约束。笔法名称作为标签。
- 低含水、短接触的笔主要由已有毛束和接纸决定。飞白可能从入口边缘的失稳延续为长缝，也可能在加压、停驻或再次接纸后补合。顿笔从减速逐步进入。水墨在湿区顺已有墨迹移动，水和颜料的库存随行程结算到下一笔。

## 从真笔到学习模型

| 试验路线 | 留下的结论 |
| --- | --- |
| 接纸、出墨时序与纸面动力学 | 模拟可核对纸上质量、余墨、离纸后变化。只保整页光学总量会移动远处旧笔的墨色，局部约束能减小这种变化。 |
| 多尺度外观、潜码与递推 | 实写直接编码可以保住细毫，纯粗导引生成仍会断散。真实历史能提高下一列的预测概率，闭环生成却会累积误差。仅匹配频带会放过格纹、顺序变化及侧别错误。 |
| 实写局部匹配 | 学接缝和墨深能改善某些读数。实写自身的墨深差回放误差约 0.007。允许查看目标选择范笔时，灰度误差还有 0.349，表明现有样本覆盖和对齐都有差距。 |
| 文字跟画 | 补清接点能改善轮廓连接。四笔勾线与两笔侧锋加皴中，锁定路径后折角软团与浓边断散仍可见。保留[锁定的文字](../sandboxes/text-to-brush/teaching-text.md)及配套结构化输入。 |

## 当前检查

兴杰实拍整笔留出。最新接缝与有界墨深校正把墨深第 90 百分位误差由 0.795 降至 0.356，灰度相对误差为 0.417，已有多尺度基线为 0.368。以各自笔迹包络为参照，首个种子的横向墨深重心约 0.485，实写为 0.565。收顿前浓墨边的位置和接续仍能直接区分。

分别核对艺学绘侧锋三笔、Gathered 五笔。组合模型没有一笔同时进入现有八项实写互差。逐列保色又近似保谱的置乱则有三笔和四笔入围。这个结果要求增加墨带位置与局部连接的判断，并与原图盲比同用。清华侧锋实写接纸宽约 291 原像素，匹配版使用的样本宽为 55–62 像素，细纹可用分辨率偏低。
