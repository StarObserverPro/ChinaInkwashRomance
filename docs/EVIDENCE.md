# 证据保留和轮换

[`evidence/current/`](../evidence/current/) 是公开的当前证据。保留一组可复跑的项目自生成笔迹及其账量，以及当前模型的留出评分摘要。原始图像、视频、第三方教材裁窗、整套评估结果和中间产物放在本地，学习笔记承接可复用的结论。

## 每次学习版本更新时

1. 给新证据标记对应模型与版本，核对训练组、留出组、用的粗导引和物理尺度。
2. 新结果能覆盖同一项检查时，用同一变更替换 `evidence/current/` 的旧结果。若新版本暂时沿用旧对照以解释变化，在摘要中标注两者版本。
3. 到第二个后续学习版本时，移除工作树中仍遗留的过时图、视频、表和未使用的临时权重。保留仍用来运行或继续训练的权重和校准配置。Git 历史可查已发布的证据。

发布前核对 `git diff --cached --name-only`。仅读取本地的参考源和 `.build/`、浏览器捕获、训练缓存、旧 `results/` 与导出的 Blender 视频不属于证据提交。真实资料在[训练文档](TRAINING.md)记录来源。当前的 [三笔图](../evidence/current/three-strokes.png)是模拟，验证库存和调用行为。[评分摘要](../evidence/current/held-out.json)单独记录实写留出的外观检验。
