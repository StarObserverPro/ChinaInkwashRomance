# 项目范围与接口

**目标**是把中国画的用笔、墨色与纸面成迹做成可调用的底层，然后让场景按笔序显示落墨、减速、停顿和洇开。教学和标定以中国画的毛笔、宣纸及笔法为依据。

| 层 | 输入与输出 | 当前状态 |
| --- | --- | --- |
| 指令与动作 | 笔法、起止、接点以及轨迹、触纸、时间、法向力、锋尖投影、倾角和滚转 | 文字跟画已试六笔。文字给的连接关系与实写推回的诊断坐标须分别记录。 |
| 笔与纸 | 毫米画布、像素采样、笔尖与两侧笔腹的水和颜料、纸上含水和颜料 | 同一状态可从干拖进入湿区。顿笔和水分沿已有墨迹的传播使用独立的过程量。 |
| 学习成迹 | 粗墨面、接纸宽、接触含水及可用过程观测 | 多尺度权重可运行。逐列模型、实写局部匹配及联合评分作为独立研究路线。 |
| 场景 | 墨层、内部覆盖、有效画幅及时间 | R02 和 Blender 原型各有入口。评审后按景片接口接线。 |

`render_stroke(request, engine=engine)` 返回 `opacity`、`paper`、`brush` 和 `ledger`。毫米坐标从纸面左上角量，向右和向下为正。时间以秒计，载水和颜料以 mg 计，颜料密度以 mg/mm² 计。各自沿用返回的纸、笔状态即可接下一笔。墨深是由像素亮度换算的光学代理，照片上有关力道、用水与实物尺度的缺测项单独记录。 [接口和示例](TRAINING.md)

## 下一阶段

1. **先把动作与成迹配对。** 从右手同一类侧锋拖笔开始，记录实物标尺、锋尖和笔腹接纸位置、落笔、行笔、连续减速、顿、提。先用已有视频核对字段。首批暂定三个独立批次，每批两档载墨、各四笔，整批留出。
2. **先学接纸与给墨。** 固定外观模型和种子，分别输入实写低频墨面、当前动力学粗场和新预测粗场，比较带方向的横向墨量、行转顿和收梢。再用预测粗场训练细纹，通过后增加同一支笔连画三笔、中锋和湿笔。
3. **联合评分与原图盲比。** 在同一物理尺度比较轮廓、偏心率、两边粗糙度、墨深和分布、飞白几何与相邻墨带、沿笔连续性及方向频谱。保留逐列保色及近似保谱的反例。独立批次优于当前基线，并在原像素盲比和反例上通过，再接回文字跟画和景片。
